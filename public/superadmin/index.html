📌 What does "@" mean?

In DNS management, @ represents your root/apex domain (e.g. school.edu without "www"). If your registrar does not allow "@", leave the Name/Host field blank.

⏱️ TTL & Propagation

Set TTL to 600 seconds (10 minutes) or your registrar's lowest option (Auto / 1/2 hour). Public DNS changes usually take 5–30 minutes (up to 24–48 hours) to propagate globally.

📖 Domain Registrar Setup Instructions

🟡 GoDaddy DNS Setup Guide ▼

1. Sign In: Log in to your GoDaddy Domain Portfolio.

2. Manage DNS: Click on your domain → select DNS (or Manage DNS).

3. Add Records: Under DNS Records, click Add New Record.

4. Root Apex Domain: If adding your root domain (e.g. school.edu), select Type A, Name @, Value 76.76.21.21, TTL 600 seconds (or 1/2 hour). Click Save.

5. Subdomain or WWW: If adding a subdomain (e.g. www or portal), select Type CNAME, Name www, Value cname.vercel-dns.com, TTL 600 seconds. Click Save.

6. Verify: Return to this screen after 5–15 minutes and click Verify DNS Records Now.

🟣 Hostinger (hPanel) DNS Setup Guide ▼

1. Sign In: Log in to Hostinger hPanel.

2. Open DNS Zone: Navigate to Domains → select domain → DNS / Nameservers → DNS Zone Manager.

3. Add DNS Records: Under Manage DNS records:

• For root domain: Type A, Name @, Points to 76.76.21.21, TTL 600. Click Add Record.

• For subdomain or www: Type CNAME, Name www, Target cname.vercel-dns.com, TTL 600. Click Add Record.

4. Free SSL: Under Websites → Security → SSL, confirm Lifetime Free SSL is active.

🟠 Cloudflare DNS Setup Guide ▼

1. Sign In: Log in to Cloudflare Dashboard and select your school domain.

2. Records: Go to DNS → Records → click Add record.

• For root: Type A, Name @, IPv4 76.76.21.21, TTL Auto.

• For subdomain: Type CNAME, Name www (or subdomain), Target cname.vercel-dns.com, TTL Auto.

3. Proxy Status: Set Proxy status to DNS only (grey cloud) during initial verification.

4. Save: Click Save. Changes on Cloudflare resolve within 2–5 minutes.

🌐 Other DNS Registrars (Namecheap, BigRock, AWS Route 53, etc.) ▼

1. DNS Management: Log in to your domain provider and navigate to DNS Settings or Advanced DNS.

2. Create Records: Add the exact Type, Name, and Value shown in the table above.

3. Host/Name: Use @ (or leave blank if your provider does not support "@" for the apex domain).

4. TTL: Set TTL to 600 seconds (or lowest available option).

5. Verify: Return here and click Verify DNS Records Now.
